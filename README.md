## Windows

TellyFox for Windows 10 and 11 is downloaded from **tellyfox.com/download/windows** (one installer, `TellyFox-Setup-<version>.exe`). The installer is kept here in two parts (GitHub's file size limit); the website joins them.

## macOS

TellyFox for macOS 12 and newer (Intel and Apple Silicon) is downloaded from **tellyfox.com/download/mac** (one installer, `TellyFox-<version>-mac.dmg`). The installer is kept here in parts (GitHub's file size limit); the website joins them.
